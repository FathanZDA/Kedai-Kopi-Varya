### Admin

**Akses Fitur (Use Case):**

* Dapat melakukan login ke sistem.


* Dapat melihat dashboard admin.


* Dapat mengelola menu (melakukan aksi CRUD: *Create, Read, Update, Delete*).


* Dapat melihat laporan penjualan.


* Dapat mengatur konten iklan.


* Dapat mengedit jam operasional.


* Dapat mengatur info lokasi.



**Alur Aktivitas (Flowchart):**

* Admin memulai dengan login sebagai admin.


* Sistem akan menampilkan halaman Dashboard.


* Sistem akan menyajikan beberapa fitur yang bisa dikelola (seperti: Kelola menu, Laporan Penjualan, Pengaturan toko, atau mengunjungi website layaknya Pelanggan A).


* Admin memilih fitur yang ingin diubah dan mulai mengelola data fitur tersebut.


* Setelah perubahan dilakukan, sistem akan menyimpan perubahan.


* Sistem akan menanyakan apakah admin ingin mengakses/mengelola fitur lain. Jika ya, admin kembali memilih fitur; jika tidak, sesi berakhir.
